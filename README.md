# QuickJokes (Быстрые шуточки)

Офлайн-тренажёр шуток для Android: выбираешь тему, в течение заданного времени сочиняешь шутки (текстом или голосом), а приложение считает шутки в минуту, начисляет монеты, ведёт статистику, серию дней и достижения.

Приложение полностью работает без интернета — разрешение на сеть не запрашивается. Интерфейс полностью на русском языке.

## Возможности

- **Тренировочные сессии**: таймер, три уровня сложности, три режима ввода (текст / голос / оба).
- **16 предустановленных тем** (текстовые и «ситуации»), часть открывается за монеты.
- **Свои темы**: текст, картинка из галереи или описание ситуации; слоты под собственные темы покупаются в магазине.
- **Голосовой ввод**: запись шутки с микрофона, прослушивание прямо в истории.
- **Экономика**: монеты за шутки и выполненное время, бонусы за темп, премия за цель, ежедневный бонус с серией входов.
- **Достижения**: 18 достижений по темпу, количеству шуток, серии, темам и кастомным темам.
- **Статистика и история**: все сессии с детализацией, агрегаты по шуткам, темпу и сериям.
- **Ежедневное напоминание** о тренировке в выбранное время.
- **Экспорт / импорт данных** в JSON-файл (включая картинки и голосовые записи) через системный файловый менеджер.
- **Темы оформления**: системная / светлая / тёмная.

## Технологии

- Kotlin 2.0, Jetpack Compose (Material 3), Navigation Compose
- Hilt (DI), Room (БД), DataStore Preferences
- WorkManager (напоминания), Coil (картинки)
- Coroutines / Flow, MVVM: `Screen → ViewModel → Repository → DAO`
- `java.time` на Android 7.x через core library desugaring

Минимальная версия Android — 7.0 (API 24), целевая — API 36.

## Структура проекта

```
app/src/main/java/com/unfallenmore/quickjokes/
├── MainActivity.kt            # единственная Activity, Compose-контент
├── QuickJokesApp.kt           # Application + Hilt
├── navigation/                # маршруты и корневой NavHost с нижним меню
├── ui/                        # экраны: home, session, results, history,
│                              # stats, achievements, shop, topics, settings, ...
│   ├── components/            # общие элементы (монеты, аудиоплеер)
│   └── theme/                 # палитра, типографика, темы
├── domain/                    # чистая бизнес-логика без Android:
│                              # RewardCalculator, DailyBonusCalculator,
│                              # JokeRules, AchievementRules, ReminderTime, ...
├── data/
│   ├── local/                 # Room: база, DAO, сущности, схемы
│   ├── repository/            # источники данных, монетный реестр, бэкап
│   ├── backup/                # JSON-кодек экспорта/импорта
│   ├── notifications/         # напоминания (WorkManager)
│   ├── seed/                  # каталог достижений и стартовые темы
│   ├── audio/                 # запись голосовых шуток
│   └── model/                 # перечисления предметной области
└── di/                        # модули Hilt (Database, DataStore)

app/src/main/assets/topics.json  # предустановленные темы (фиксированные id < 0)
app/schemas/                     # схемы Room для миграций
```

Сложность сессии (`data/model/Enums.kt`) задаёт базовую награду, длительность, целевой темп (JPM) и пороги бонусов:

| Сложность | Длительность | Цель | База | Бонус за цель |
| --- | --- | --- | --- | --- |
| Легко | 120 с | 3 JPM | 5 | +3 |
| Средне | 60 с | 4 JPM | 10 | +5 |
| Сложно | 30 с | 6 JPM | 15 | +8 |

Итоговая награда: пропорциональная база за отработанное время + 1 монета за шутку + бонус за темп (+5/+10) + премия за достижение цели. Сессия без единой шутки не оплачивается.

## Сборка

Требования: Android Studio (JDK 11+ в комплекте), Android SDK 36.

```bash
# отладочная сборка
./gradlew assembleDebug          # Windows: gradlew.bat assembleDebug

# установка на подключённое устройство/эмулятор
./gradlew installDebug
```

## Тесты

Чистая доменная логика (награды, бонусы, JPM, валидация шуток, напоминания, бэкап-кодек) покрыта unit-тестами, поэтому проверяется без устройства:

```bash
./gradlew test                   # юнит-тесты
./gradlew connectedAndroidTest   # инструментальные (нужен эмулятор/устройство)
```

## Подпись релиза

Для сборки подписного release APK/AAB создай в корне проекта файл `keystore.properties`:

```properties
storeFile=/путь/к/upload-keystore.jks
storePassword=...
keyAlias=upload
keyPassword=...
```

Без этого файла release-сборка подписывается debug-ключом — удобно, чтобы локально проверить работу R8 (обфускация + сжатие ресурсов включены).

## Разрешения

- `RECORD_AUDIO` — запись голосовых шуток (запрашивается при входе в голосовой режим).
- `POST_NOTIFICATIONS` — ежедневные напоминания (запрашивается на Android 13+).

## Бэкап

Экспорт создаёт JSON-файл вида `{"format": "quickjokes-backup", "version": 1, ...}` с профилем, днями входов, достижениями, операциями с монетами, своими темами, сессиями и шутками; картинки тем и голосовые записи вкладываются в base64. Импорт совместим со старыми версиями файла: неизвестные значения перечислений и отсутствующие поля деградируют к значениям по умолчанию.
